# Калібрування ймовірності тривоги

`build.py` будує модель для вкладки «Ймовірність» (`app/src/main/res/raw/chance_model.json`).

Дані:
- офіційна історія тривог по районах — https://github.com/Vadimkin/ukrainian-air-raid-sirens-dataset (`datasets/official_data_uk.csv`);
- історія каналу Повітряних сил (`kpszsu`) — збирається workflow «Історія Telegram», потім «Опублікувати дані калібрування» кладе її в гілку `data`.

Запуск: `python3 build.py official_data_uk.csv chance_model.json kpszsu.jsonl.gz`

Модель: логістична регресія, прогноз «тривога почнеться протягом 30 хв», ознаки — район (частота), година доби,
тривоги в інших районах області та в сусідніх областях, нові тривоги за 20–30 хв, масштаб атаки, нещодавній відбій,
згадки регіону Повітряними силами. Перевірка — на днях після 2026-07-20, яких модель не бачила.
